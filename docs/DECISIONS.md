## مصادر البيانات

| المزود | الخطة | الحد | شكل الرمز | الدور |
|--------|-------|------|-----------|--------|
| SAHMK | Enterprise | 1,000/د | `2222` | أساسي لحظي (WebSocket كل 3 ثوانٍ) |
| LSEG | Pro | 2,000/س | `2222.SR` | تاريخي + failover كل 10 ثوانٍ + إغلاق |
| MarketAux | Professional | 200/د | `2222` | أخبار ومشاعر |
| Tadawul API | — | — | `2222` | احتياطي ثالث |
| Alpha Vantage | مجاني | — | `2222.SR` | احتياطي إضافي |

**سلسلة Failover أثناء الجلسة:** SAHMK → LSEG → Tadawul → Redis  
**بعد الإغلاق:** LSEG close → Redis

## التغطية

- 350+ شركة: بيانات أساسية (`coverage_tier=basic`)
- 120 شركة: نماذج متقدمة (`coverage_tier=advanced`) تُحدَّث شهرياً
- إضافة يدوية: `coverage_tier=manual`

- أساسي: 5 أيام
- اختياري: 10 و 20 يوم
- جدولة: 06:00 و 12:00 Asia/Riyadh (أحد–خميس)
