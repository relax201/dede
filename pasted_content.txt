أنشئ لي منصّة احترافية لتحليل الأسهم السعودية (تاسي) مع أسعار لحظية حقيقية + نظام توصيات آلي، بواجهة عربية RTL متجاوبة، وجاهزة للنشر. ممنوع استخدام أي بيانات وهمية أو محاكاة.

1) المتطلبات الجوهرية

جلب أسعار الأسهم السعودية Real-Time من مزوّد بيانات قانوني يدعم السوق السعودي (مثلاً: Twelve Data، Tiingo، marketstack، أو مزوّد مرخّص لتداول/تاسي). يجب أن تعرض اسم الشركة + الرمز + السعر الحالي + نسبة التغيّر + آخر تحديث.

لا تستخدم أي سكريبر من مواقع مخالفة الشروط. الالتزام التام بالتراخيص وسياسات الاستخدام.

في حال تطلب المزود اشتراكًا، جهّز الكود مع مفاتيح .env وتحقّق من تدفّق البيانات عبر Endpoint Mock بسيط مؤقت لمرحلة التطوير فقط، ثم اربطه بالـ API الحقيقي عند وضع المفتاح (لكن الموقع عند التشغيل النهائي يجب أن يعمل على البيانات الحقيقية).

2) المعمارية والتقنيات

Frontend: React أو Next.js (مفضّل Next.js 14 App Router)، TypeScript، RTL جاهز، تصميم حديث (Tailwind أو Bootstrap) مع خط عربي جميل (Tajawal).

Backend: FastAPI (Python) أو Node.js (Express/Fastify) – اختر الأفضل؛ أنا أفضّل FastAPI.

قاعدة البيانات: PostgreSQL (أو Supabase). استخدم SQLAlchemy/Prisma.

الزمن والمنطقة: Asia/Riyadh، تنسيق عرض التواريخ والأوقات هجري/ميلادي اختياري.

التحديث اللحظي: WebSocket/SSE لتدفق الأسعار والتوصيات المباشرة.

النشر: Frontend على Vercel، Backend على Railway/Render، DB على Railway/Supabase.

3) الميزات الأساسية (واجهة المستخدم)

صفحة رئيسية تعرض نظرة عامة للسوق (مؤشر تاسي، أكبر الرابحين/الخاسرين، القطاعات).

بحث ذكي بالاسم/الرمز، مع إكمال تلقائي.

صفحة تفاصيل السهم: سعر حي، تغيّر فوري، مخطط تفاعلي (1د، 5د، 15د، 1س، يومي)، أحجام تداول، أعلى/أدنى، عمق السوق إن توفّر، وأخبار مرتبطة إن وجدت API قانوني.

نظام توصيات: إشارات شراء/بيع/حياد مع سبب مختصر، وثقة الإشارة، ووقف خسارة/أهداف.

قائمة مراقبة (Watchlist) محفوظة للمستخدمين مع تنبيهات.

سجل الأداء: إحصائيات دقة التوصيات التاريخية (Win Rate، متوسط R/R).

دعم اللغة العربية بالكامل (RTL) + إمكانية الإنجليزية لاحقًا.

4) محرّك التوصيات (Baseline):

اعتمد مؤشرات تقنية أساسية: RSI، MACD، EMA(8/21/50/200)، Volume spike، ATR لاحتساب الوقف.

فلترة الاتجاه العام (Trend filter) عبر EMAs أو Supertrend.

قواعد واضحة لتوليد الإشارة (مثال: تقاطع MACD + RSI خروج من التشبّع + السعر فوق EMA50).

معايرة الإطار الزمني (افتراضي: 15د/1س/يومي) وإجماع الأطر (Multi-TF Confirmation).

لا تستخدم ML معقّد الآن؛ فقط بنية نظيفة تسمح بإضافته لاحقًا.

5) الـ Backend: نقاط نهاية (API) مقترحة

GET /api/health — فحص الصحة.

GET /api/symbols — قائمة رموز تاسي + الأسماء + القطاع.

GET /api/quote?symbol=XXXX — سعر حي + تغيرات + آخر تحديث.

GET /api/candles?symbol=XXXX&tf=15m&limit=500 — شموع للرسوم والتحليل.

GET /api/recommendation?symbol=XXXX — توصية لحظية + تفاصيل (أسباب، SL/TP).

GET /api/top-movers — أكبر الرابحين/الخاسرين اليوم.

GET /api/sector-stats — ملخص القطاعات.

POST /api/watchlist (JWT) — إضافة/حذف من المراقبة.

GET /api/performance — إحصائيات أداء التوصيات التاريخية.

WebSocket: /ws/stream لبث الأسعار/التوصيات مباشرة.

6) قاعدة البيانات (جداول مقترحة)

symbols(id, ticker, name_ar, name_en, sector, status)

prices(id, symbol_id, ts, open, high, low, close, volume) (تخزين جزئي لأغراض التحليل/الأرشفة)

signals(id, symbol_id, ts, timeframe, signal_type, confidence, entry, sl, tp1, tp2, reason)

users(id, email, password_hash, role) + watchlists(user_id, symbol_id)

executions(id, signal_id, outcome, rr, hit_tp, hit_sl, notes)

7) الواجهة والتصميم

صفحة Dashboard أنيقة: بطاقات KPIs، جدوليْن: رابحين/خاسرين، مخطط لمؤشر تاسي، Heatmap للقطاعات.

صفحة السهم: شارت تفاعلي (مثلاً lightweight-charts)، صندوق توصية كبير (حالة الإشارة، Entry/SL/TP، سبب مختصر)، مؤشرات أسفل الشارت.

صفحة “التوصيات الحية”: تدفق بطاقات إشارات جديدة مع فلتر بالقطاع/الثقة.

صفحة “قائمة المراقبة”: إدارة قائمة المستخدم وتنبيهات.

دعم الوضع الليلي/النهاري.

8) التنبيهات والتكاملات

بوت تيليجرام: إرسال إشعار تلقائي عند توصية قوية/تحقق هدف/ضرب وقف.

بريد إلكتروني اختيارياً (SMTP).

9) الأمان والجودة

JWT للمصادقة، CORS مضبوط، Rate-Limiting على نقاط الأسعار، تعقيم المدخلات.

سجلات (Logging) منظمة، مراقبة أخطاء (Sentry اختياري)، اختبارات وحدة وتكامل أساسية.

احترام حدود مزود البيانات (Requests/Rate Limits) مع Cache قصير (Redis اختياري).

10) الأداء

استخدام Server-Side Rendering لصفحات عامّة سريعة، وIncremental Revalidation للبيانات شبه الثابتة.

بث الأسعار عبر WebSocket/SSE لتقليل الاستهلاك.

12) أوامر تشغيل ونشر

Backend: uvicorn app.main:app --host 0.0.0.0 --port 5001

Frontend: pnpm install && pnpm build && pnpm start (أو next start)

تعليمات لنشر: Vercel للواجهة، Railway/Render للباك.

13) التسليمات المطلوبة

مشروع كامل (Frontend + Backend + DB Migrations) في مجلد واحد، مع README عربي واضح وخطوات تشغيل محلي ونشر.

تصميم احترافي RTL وخط Tajawal، مع صور/أيقونات خفيفة.

ملف Postman/Thunder لاختبار الـ APIs.

عينات بيانات واقعية من المزود عند توفّر المفتاح، وإلا تأكّد أن التشغيل النهائي يعتمد على API حقيقي فور وضع المفتاح.

14) معايير القبول

عند وضع مفتاح API حقيقي، تُعرض أسعار حيّة لجميع رموز تاسي المدعومة.

ظهور التوصيات اللحظية وتحدّثها أمام المستخدم، وإمكانية إرسال تنبيه تيليجرام.

البحث بالرمز/الاسم يعمل عربيًا، والواجهة سريعة ومتجاوبة (موبايل/ديسكتوب).

لا توجد محاكاة أو بيانات يدوية في البيئة النهائية.

وجود سجل أداء يحسب نتائج التوصيات بعد تحقّق TP/SL.

ملاحظات أخيرة

اكتب الكود بنظافة عالية وتعليقات واضحة، وهيكل مجلدات احترافي.

جهّز نقاط توسيع مستقبلية (إضافة ML/outliers/news-sentiment لاحقًا).

احرص على أن تكون جميع الأسماء والمحتوى باللغة العربية بشكل افتراضي
